      Rumble account (for sending)

      Log in on rumble.com in your browser, press F12 → Application (Chrome/Edge) or Storage (Firefox) → Cookies → https://rumble.com, and copy the value of u_s. It's encrypted on this PC. It stops working if you log out of rumble.com; just paste a new one then.

      What this option does: the plugin logs in to Rumble as you, the same way rumble.com's login page does, so it can post chat messages from your account and log back in by itself whenever the session expires.

      Your username and password are stored only on this PC, in %APPDATA%\casterlabs-caffeinated\rumble-chat\account.json, and the password is encrypted with Windows' built-in protection (DPAPI) so only your Windows user account can decrypt it. Anyone who can use your Windows account could use it.

      Your password is only ever sent to rumble.com (as the salted hashes Rumble's own login uses). It is never logged, and never sent to Casterlabs or anyone else.

      If your Rumble account has 2FA, you'll be asked for a code whenever Rumble needs a fresh login. Rumble's login and chat endpoints are unofficial and may change. Use "Forget Rumble login" to delete everything at any time.
